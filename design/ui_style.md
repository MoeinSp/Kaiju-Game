# سبک متن‌های ربات کایجو (خلاصه‌ی قانون‌ها)

> نسخه‌ی کامل: `design/ui_polish_prompt.md` · کد: `game/ui.py` · صاحب پروژه، ۱۴۰۵/۰۸/۲۱

## چیزی که خودکار انجام می‌شه (هوک ارسال در `bot/main.py` ← `ui.polish`)
روی هر پیام، کپشن، برچسب دکمه و آلرت — لازم نیست دستی کاری کنی:
- ارقام فارسی/عربی ← انگلیسی («٬ ٫ ٪» ← «, . %»).
- «3 از 7»، «120/400»، «157,000 / 157,000» ← `<code>3/7</code>` (مقدار پرشدنی، حالت کپی).
- `<code>1,234</code>` (عدد خالی توی باکس خاکستری) ← `<b>1,234</b>`. لینک، شناسه و `#72` توی code می‌مونن.
- کلمه‌های لاتین (اسم بازیکن، DNA، VIP) و عددهای علامت‌دار («-1235»، «+341») ایزوله (FSI…PDI) می‌شن.
- `XP` ← «تجربه»، `vs` ← «⚔️»، `Lv` ← «سطح»؛ «طلا II» ← «طلا 2».
- « | »، « │ »، « ┃ » ← « · »؛ «[■■□□]» ← «■■□□».
- خطی که اولین حرف قویش فارسی نیست ← RLM اول خط؛ «4.» اول خط ← ایزوله.
- هیچ خط خالی کنار جداکننده، هیچ دو خط خالی پشت‌سرهم؛ جداکننده‌ی سوم به بعد حذف.
- بیشتر از ۱۰۰ ایموجی پریمیوم ← اضافه‌ها ساده می‌شن (جداکننده‌ها می‌مونن).
- اگه تلگرام متن پرداخت‌شده رو رد کنه، همون نسخه‌ی قبلی فرستاده می‌شه.

## چیزی که موقع نوشتن صفحه‌ی جدید رعایت کن
- اسکلت: عنوان (یک خط) · زیرعنوان `<i>` (اختیاری) · جداکننده · بخش‌ها با یک خط خالی · جداکننده · جمع‌بندی. از `ui.screen()` استفاده کن.
- هر خط ≤ ۳۲ حرف (سقف ۴۰). خط بلند ← دو خط، خط دوم با تورفتگی `"      "`.
- ایموجی/آیکون **قبل** از عدد: «💎 20 · 🪙 40 هزار · 🧬 2 هزار»؛ علامت `+`/`-` نچسبه به عدد.
- عنصر با « · » بیاد، نه داخل پرانتز/براکت: «کرکدان · 🪨 خاک».
- اعداد: `ui.num` (1,234)، `ui.short` (120 هزار)، `ui.pct` (35%)، `ui.dur` (2 روز و 4 ساعت)، `ui.jdate` (15 مهر 1405)، `ui.fill` (`<code>30/30</code>`).
- بولد فقط برای عنوان، عدد اصلی خط و نتیجه؛ ایتالیک فقط برای توضیح.
- دکمه: ≤ ۱۸ حرف، فارسی، ایموجی از `emoji_key` (نه داخل متن).
- **هیچ اطلاعاتی حذف نشه** — مینیمال یعنی شلوغی کمتر، نه اطلاعات کمتر.
